# Academia Virtual de Damas - Alma

Tabuleiro virtual animado para praticar combinações nas aberturas de damas.

## 🎮 Funcionalidades

- **Tabuleiro Interativo**: Clique nas peças para selecionar e mova-as
- **Combinações Prontas**: 3 combinações de exemplo incluindo aberturas clássicas
- **Animações**: Visualize movimentos com animações suaves
- **Responsivo**: Funciona em desktop e mobile

## 📚 Conteúdos

- Curso Treinamento de Cálculo
- Combinações nas Aberturas
- 48 Aberturas Analisadas
- Coleção de Livros e Apostilas Brasileiros
- Coleção de Livros Russos Traduzidos
- Padrões de Combinações (Método Russo)
- Jogos Selecionados - Campeões Mundiais e Brasileiros

## 🚀 Uso

1. Abra `index.html` em qualquer navegador moderno
2. Clique em "Carregar Exemplo" para ver uma posição inicial
3. Selecione peças clicando nelas
4. Clique em casas vazias para mover
5. Use os botões para navegar entre combinações
